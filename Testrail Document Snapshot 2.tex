\subsection{Testing Overview}

Testing for Snapshot 2 focused on validating the new interactive map and location-based AQI monitoring features implemented in the AirWatch platform. QA testing covered map rendering, AQI overlays, geolocation, location search, and saved locations persistence across mobile and web environments.

\subsection{Key Testing Areas}

\subsubsection{Interactive Map Rendering}
\begin{itemize}
    \item Verified Mapbox rendering on web
    \item Verified react-native-maps functionality on mobile
    \item Tested zooming, panning, and tile loading behavior
\end{itemize}

\subsubsection{AQI Heat-Map Validation}
\begin{itemize}
    \item Confirmed AQI overlays displayed correctly
    \item Verified AQI severity color ranges
    \item Compared displayed AQI values against API responses
\end{itemize}

\subsubsection{Geolocation \& Search}
\begin{itemize}
    \item Tested GPS location detection
    \item Validated Google Places autocomplete functionality
    \item Verified reverse geocoding accuracy
\end{itemize}

\subsubsection{Saved Locations}
\begin{itemize}
    \item Confirmed users could save multiple locations
    \item Verified persistence after app restart
\end{itemize}

\subsection{QA Reflection}

Testing during Snapshot 2 demonstrated the importance of cross-platform testing for map rendering and geolocation functionality. Several issues only appeared on physical mobile devices and were not reproducible in browser testing environments.

The team also identified performance optimization as a future priority due to rendering delays on lower-end devices.

\subsection{Final Assessment}

Snapshot 2 objectives were successfully completed with most core features operating as expected. Remaining issues were minor performance and navigation-related defects scheduled for future optimization.
