\section{Introduction}

\subsection{Purpose}
This document specifies the software requirements for AirWatch, a cross-platform weather and air pollution monitoring application. It defines what the system shall do (functional requirements) and the quality attributes the system shall satisfy (non-functional requirements).

\subsection{Intended Audience}
\begin{enumerate}
    \item Development team (implementation reference)
    \item QA team (test case derivation)
    \item Project stakeholders (scope agreement)
\end{enumerate}

\subsection{System Overview}
AirWatch aggregates real-time weather and AQI data, presents it via an interactive map, delivers push notifications for threshold breaches, and provides EPA-aligned health advisories on mobile (iOS/Android) and web platforms.

\section{Overall Description}

\subsection{Product Perspective}
AirWatch is a standalone application communicating with third-party data APIs via a proprietary back-end API layer. It operates on iOS 15+, Android 10+, and modern web browsers (Chrome 100+, Firefox 100+, Safari 15+).

\subsection{Assumptions \& Dependencies}
\begin{enumerate}
    \item Users have an active internet connection during primary usage
    \item Third-party API uptime: OpenWeatherMap and AirVisual maintain $>$99.5\% uptime SLAs
    \item Device location services are enabled by the user
\end{enumerate}

\section{External Interface Requirements}

\subsection{User Interfaces}
\begin{enumerate}
    \item Home Screen: AQI summary card, weather stats, 7-day forecast strip
    \item Map Screen: Full-screen interactive map with heat-map overlay, search bar
    \item Location Detail Screen: Full weather + AQI breakdown, trend chart, health advisory
    \item Alerts Feed Screen: Chronological list of dismissed/active advisories
    \item Settings Screen: Account, notification preferences, theme toggle
\end{enumerate}

\subsection{API Interfaces}
\begin{enumerate}
    \item OpenWeatherMap One Call API 2.5 -- weather data
    \item AirVisual Nearest City API v2 -- AQI and pollutant data
    \item Google Places Autocomplete v1 -- location search
    \item Mapbox Maps API v3 -- map tiles and custom layers
\end{enumerate}

\subsection{Hardware Interfaces}
\begin{enumerate}
    \item GPS/Location Services -- device location requested at runtime
    \item Push Notification Service -- FCM (Android) / APNs (iOS)
    \item Camera -- not used in v1.0
\end{enumerate}
